KMeans Clustering - Explanation

What is KMeans?
KMeans is an unsupervised machine learning algorithm used to group data into clusters based on similarity. It works by dividing data into K groups, where each group is represented by a centroid.

How does it work?

  1. Select the number of clusters (K)
  2. Initialize random centroids
  3. Assign each point to the nearest centroid
  4. Recalculate centroids based on assigned points
  5. Repeat until convergence

Why use KMeans?
It helps discover hidden patterns in data without needing labeled outputs. It is widely used in segmentation, recommendation systems, and data analysis.

In this project:
We use KMeans to group individuals based on health data (Age and Weight), allowing us to identify similar profiles.
