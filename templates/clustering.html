Clustering Application

  • Problem description:
    The goal is to group individuals based on their health characteristics such as age and weight. This allows identifying patterns or segments within the population without prior labels.
  • Dataset explanation:
    The dataset contains health-related information including Age, Weight, Height, BMI, and other variables. For this clustering task, we selected Age and Weight to visualize the groups in a 2D space.
  • Model training:
    We used the KMeans algorithm, an unsupervised learning technique. The data was first standardized using StandardScaler, and then grouped into 3 clusters. The model iteratively adjusts the centroids until convergence.
